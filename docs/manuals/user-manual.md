# Manuale utente Blog

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Blog separa redazione, revisione e pubblicazione.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Visitatore/utente | Consulta solo contenuti pubblicati. |
| Gruppo/editor | Modifica contenuti nel perimetro autorizzato. |
| Admin/super-admin | Gestisce risorse, stato editoriale e tassonomie. |

La view non deve pubblicare un contenuto ignorando lo stato editoriale.
