# Story 3.6 — PHPStan Blog Module: 12 Errors

## Problem

PHPStan analysis on Modules/Blog reports 12 errors.

## Error Details

### 1. Cast errors
```
app/Filament/Resources/TextWidgetResource/Pages/EditTextWidget.php
  26  Cannot cast mixed to string

app/View/Composers/Support/ThemeCategoryQueries.php
  49  Cannot cast mixed to int
```

### Error Types
- `cast.string` - Cannot cast mixed to string
- `cast.int` - Cannot cast mixed to int

## Solutions

### EditTextWidget.php line 26
```php
// WRONG
$value = (string) $data['key'];

// CORRECT - add type check
$value = is_string($data['key'] ?? null) ? $data['key'] : '';
```

### ThemeCategoryQueries.php line 49
```php
// WRONG
$id = (int) $mixedValue;

// CORRECT - add type check
$id = is_numeric($mixedValue) ? (int) $mixedValue : 0;
```
