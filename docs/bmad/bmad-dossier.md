# Blog — BMAD dossier
## Product brief / PRD
Publish municipal/editorial content independently from civic Ticket workflow.
## Architecture / UX / security
Blog owns article lifecycle and permissions; Cms/Lang/Seo provide presentation/localization; tenant and author scopes are explicit.

Draft/publish; moderation/permissions; localized metadata/feed. Stories cover schedule, media rights and sitemap inclusion.
